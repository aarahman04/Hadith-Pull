# Looks (2026-11-14)

About › Appearance › Look offers Classic plus five complete looks, matching Android's `Look` setting: Mushaf, Iznik, Mihrab, Riyad and Kufic. Each has a light and a dark that keep the same parts and roles.

- Stored in `localStorage.look` and applied before first paint as `html[data-look]` by each page's boot script (beside `theme`). Classic is the absence of the attribute.
- `style.css`, between `LOOKS:BEGIN` and `LOOKS:END`: palettes generated from Android `ui/theme/Colors.kt hadithColors()`, the look's radius tokens and card family, type, eyebrow marks (CSS masks), page art (SVG backgrounds), the Read frames (Mushaf gilded frame and red initial; Iznik tile panel and band; Mihrab pointed arch silhouette with matching mask, lantern, container-unit text offset; Riyad leaf; Kufic reference headline from `h1[data-number]`), the tab bar and buttons.
- `script.js`: `LOOKS`, `setLook`, `initAppearance` (picker with day/night previews), and the Read heading's `data-number` / `data-collection` for Kufic.
- Release tag `20261114-looks-1`; parity manifest regenerated; tests 117/117.
- Also this round: the Foundations shelf layout fix and the chain icon note (no web chain feature yet).
- Not checked: Safari, very narrow (<340px) phones, print.
