Smoother reading and navigation

Read, Bookmarks and About now load together. Switching between them keeps your current Hadith, expanded Arabic and reading position. Desktop pages fade gently; on phones, pages slide and you can swipe between the three sections.

Use the left and right arrows to switch sections. Enter, N or + draws a new narration; Space shows or hides the Arabic. Ctrl or Cmd + C copies the Hadith when no text is selected. Arrow keys, Page Up/Down and the mouse wheel scroll the narration smoothly without clicking it first.

The desktop action card includes a Keyboard shortcuts popup. It stays out of the way on phones. Shortcuts pause while you type or use a popup, and reduced-motion preferences are respected.

The green header highlight now moves and changes width between sections while the page fades. Closing the Arabic animates its spacing away with the text, without a final jump. Offline downloads show a green completion message and Available offline when the saved version is current. Update offline copy appears only for an older saved version.

The expanded reference uses aligned label and value rows on desktop, with long chapters and grades wrapping neatly in the text column. It keeps its width and text size, and phones keep the reference card.

Headings now match in size and position, the reading appearance and theme icons are aligned, and browser tabs show just the page name. The desktop reference puts the Hadith number on its own line and keeps the chapter on one line so the card stays steady. Hover over a shortened chapter title to read it in full, or expand the reference. Bookmarks is simpler, and the offline and calendar buttons are more compact.

The same Hadith Pull, on the web

Thank you for using Hadith Pull. I made this project so you can go through the hadith on Sunnah.com more easily.

If you want to cross-check a hadith, every one has a Sunnah.com link, and you can check its book reference and grading as well.

The website now uses the same Sunnah.com dataset as the Android app. Shared links open the exact narration, including links from the app and supported older links. A missing link tells you what happened.

Sahih narrations are shown by default, with the same filters for other grades and the same selection of standalone narrations as the app. Your previous filter choice is kept.

On phones and desktops, the heading, Arabic typeface controls and actions stay in place while you scroll the narration. On a wide screen, the action card stays centered beside the reading area, with a slimmer New Hadith button.

You can move your saved folders between the website and Android using Import Library, Export Library or Share Library. Existing bookmarks on this device are kept.

Offline reading, the app's bundled fonts, calendar reminders, and open-source licenses are available from About. The offline download shows progress and a Cancel button, so you can stop it and try again later.

About also includes a download card for Hadith Pull on Android. Android's notification actions, special-day reminders and home-screen widget remain in the app.

If you have a suggestion, or find a bug or a mistake, send a message. Thank you for using Hadith Pull.
